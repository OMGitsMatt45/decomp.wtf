# decomp.wtf 0.22.0

This release expands graphics, audio and controls in generated desktop projects and improves native execution across all five supported platforms.

## Game Boy Advance

- Add saved graphics options for scaling, color and fullscreen. Add optional band-limited audio playback with saved settings.

## Nintendo DS

- Add saved audio and graphics controls. Keep animated HUD anchors separate from world overlays in enhanced views.
- Export supported enhanced cartridges in original DS (NTR) mode while retaining the complete input image. Improve startup and ARM7 recovery, cartridge capacity mapping, protected reads and infrared cartridge identification. Compatibility with enhanced cartridges is limited to their NTR execution path.
- Improve guarded Thumb dispatch, stack-restored ARM exits and callback recovery. Add reviewed native instruction alternatives and bounded cheat programs for project settings.

## PlayStation

- Improve native execution through overlays, copied code, loaded libraries, relocated callbacks and instruction-cache resume entries. Correct zero-register writes in delay slots and support additional OpenBIOS exception continuations.
- Add native cheat settings and guarded instruction variants. Route quick keyboard taps and scripted controls through the same pad sampling path.
- Add desktop graphics and audio controls and preserve the full mix in enhanced audio. Disable unqualified native snapshots while retaining in-game saves and persisted disc selection.

## PlayStation 2

- Improve native VU program generation and dispatch, including guarded ahead-of-time VU1 programs and more efficient Windows x64 vector operations.
- Reduce allocations and redundant work in VIF unpacking, DMA chains, GIF packets and GPU staging. Add an optional ordered VIF1 GIF frontend worker and improve ordered GS worker behavior.
- Add reviewed cheat alternatives and guest-frame input commands. Correct EE callback stack lifetime and Windows source export and command-file handling.

## Nintendo 3DS

- Add desktop presentation and audio controls, optional texture packs and per-frame HID input publication.
- Recover more ARM and Thumb code paths, including interworking calls, relative jump tables, constructor callbacks, VFP fragments and loop edges. Apply guarded cheat instruction patches to loaded CRO copies.
- Improve offline socket, access-control and UDS behavior. Add room interface selection, the `GetHandleInfo` supervisor call and silent microphone sampling for software that expects a microphone service.

Existing generated projects retain their own source snapshots. To use the new backend behavior, update or regenerate the project and validate its game-specific customizations.

The release gate checks the Windows application and all five native backends at the exact release commit. A separate clean Windows installation checks the packaged wheel, CLI, local web app and API. Game compatibility remains experimental and varies by title.

Download **decompnet-0.22.0-windows.zip**, extract it and run **windows.cmd**. The wheel, source distribution, installer scripts and **SHA256SUMS** are also attached. The packages contain the tool and its fixtures. Supply your own game inputs for export.
