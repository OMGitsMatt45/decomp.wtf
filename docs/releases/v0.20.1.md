# decomp.wtf 0.20.1

This patch release fixes DS shared-return translation exposed by Dragon Quest
IV's Chimera Wing travel and repairs fresh DS runtime-source installation.

- Recognize balanced compiler entry/exit instrumentation around a shared Thumb
  return. A BL into the enclosing function's return sequence consumes that
  function's saved frame and must not resume after the BL. Emit a local jump or
  an actual tail call, without a returning-call check against the BL continuation.
- Add original ARM/Thumb fixtures checking local and separately outlined shared
  returns, saved registers, caller stack balance, both branch paths and helper
  execution. Runtime return checks remain enabled in dedicated regressions.
  Malformed stack-restoration sequences are still rejected. Ordinary nested
  function calls continue to return normally.
- Update the checksum-pinned DS runtime download to the repository's canonical
  `dq9-remastered/DQ9-Remastered` location. Its commit remains unchanged; the
  renamed archive was verified against all 389 pinned Git file blobs.

The exact owner-side DQIV function was also re-emitted successfully with the
generic correction. No game addresses, ROM bytes, saves, or private game output
are included in this release. DQIV's widescreen camera and menu enhancements
remain in its separate game project. Existing generated projects keep their
source snapshot; this release does not rewrite them automatically.

For Windows, download **decompnet-0.20.1-windows.zip**, extract it and run
**windows.cmd**. The wheel, source distribution, installers and **SHA256SUMS**
are also attached. Compatibility remains experimental and title-specific;
these bounded regressions do not establish a full-game playthrough.
