# decomp.wtf 0.21.0

This release brings the shared GBA and Nintendo DS export, runtime and desktop
improvements developed during the recent game builds into a new installable
release. DS, PS1, PS2, GBA and 3DS remain the supported native PC output targets.

## Game Boy Advance

- Split large dispatch registries into bounded source fragments so generated
  projects stay within GitHub's individual-file limits.
- Improve bounded Thumb switch and packed callback discovery, including leaf
  callbacks and valid tables following rejected pointer-shaped data.
- Add an exact-ROM callback inventory audit to catch required missing entries
  and ARM/Thumb mode mismatches before compiling an export.
- Add an in-window cheat browser with project-provided catalogs, categories,
  exclusive choices and per-save preferences, plus optional native project
  hooks. Unsupported instruction-patching device codes remain rejected.
- Sample live controls after rendering and frame pacing, and correct mirrored
  cheat addresses, odd-size pixel selection and desktop stack allocation.

## Nintendo DS

- Improve module-qualified overlay and ARM7 callback recovery, mutable literal
  handling, verified protected-function boundaries and recovery ordering.
  Exclude packed ARM7 autoload payloads from executable recovery.
- Correct shared-frame Thumb long branches and loop conditions, signed range
  guards, register-preservation checks and live jump-table selector bounds.
- Support reviewed callback reference bounds tied to exact decoded-module
  hashes, and consolidate overlapping dispatch regions before emission.
- Extend GPU rendering for fog, outlines, shadows, depth-equal surfaces and
  translucency, with filtered downsampling and up to 12x internal resolution.
  Preserve captured scene origins through LCD brightness and correct sloped
  raster boundary pixels when antialiasing or edge marking is active.
- Add optional dynamic widescreen with separate geometry and UI placement.
  Follow-up fixes preserve battle panels, cinematic framing, startup menus,
  world overlays, HUD controls and stable captions as text reveals. Reuse GPU
  textures and uniform locations to reduce presentation overhead.
- Add optional original-score audio cleanup with 16-bit host output and causal
  sampled-instrument interpolation, while preserving guest sample reads,
  channel timing and capture/reverb writes. Hardware output remains the default.
  Reduce desktop sound buffering without clearing sound already queued.
- Preserve brief keyboard taps and ordered releases, clear consumed modal
  inputs, keep scripted touch active and use drawable dimensions for high-DPI
  settings captures.
- Add optional project-owned feature hooks independent of cheat menus, and
  improve offline wireless register, interrupt and power-state behavior.
  Wireless packet transport is not implemented.

## Existing projects and validation

Existing generated projects retain their own source snapshots and customizations.
Adopting a newer exporter or runtime requires an explicit project update and
validation; this release does not automatically regenerate existing games.
Title-specific cheats, cameras, event content, mobile assets and other game
enhancements remain in their separate projects.

The release gate requires successful Windows application and all five native
backend qualification workflows on the exact main-branch release commit.
Package publication additionally builds the wheel, source distribution and
Windows source/install ZIP, then installs the wheel in a clean Windows
environment and checks the CLI, application and API.

Compatibility remains experimental and game-specific. Original fixtures and
bounded gameplay checks do not certify a complete playthrough. No game ROMs,
BIOS dumps, saves or generated retail game source are included.

For Windows, download **decompnet-0.21.0-windows.zip**, extract it and run
**windows.cmd**. The wheel, source distribution, installer scripts and
**SHA256SUMS** are also attached.
