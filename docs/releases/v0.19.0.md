# decomp.wtf 0.19.0

This release brings the completed native Windows compiler paths and the first
GB/GBC assembly workflow onto the main release channel. Windows runs without
WSL. The full Linux compiler suite is checked on Ubuntu 24.04 x86-64 (MIPS
binutils needs glibc 2.38 or newer; older 32-bit compilers need `libc6-i386`).

- PS2 uses verified native hosts of the original EE-GCC 2.96 C/C++ compiler,
  with ordinary pinned installation, strict matching and byte-exact exports.
- N64 IDO 5.3 includes the distinct classic cfront pipeline and cross-unit
  template prelinking alongside the original SGI/EDG frontend.
- GBA includes separately verified normal and old agbcc C++ frontends, preserving
  each original Thumb backend. PS1 and N64 compiler paths retain their native
  Windows and Linux validation.
- GB/GBC supports browser import, editable RGBDS assembly, local agent claims,
  bank-aware byte checking and verified full-ROM exports. This is assembly
  verification; mapper analysis, richer layouts and room synchronization remain
  experimental or unfinished. It does not produce C/C++ game source.
- Fresh Windows/Linux release installs and update checks now use this fork's
  GitHub releases. Existing explicitly configured upstream installs retain their
  recorded update source.

Download **decompnet-0.19.0-windows.zip**, extract it and double-click
**windows.cmd**. Linux users can run the attached `install.sh`. The wheel,
source distribution and `SHA256SUMS` are also attached. Period toolchains are
downloaded separately with pinned checksums; proprietary compilers retain their
explicit installation step and are not bundled in these release assets.

The operational run checks application workflows, original homebrew fixtures,
compiler matching/export, GameCube and DS project rebuilding, and native Windows
behavior. The actual release wheel is separately installed and checked on both
hosts, including the local web server and authenticated API. Platform-specific
and unavailable private-ROM tests are recorded as skips in the CI results.
