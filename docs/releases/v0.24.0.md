# decomp.wtf 0.24.0

This release expands experimental Nintendo Switch source exports and adds folder-backed disc assets for eligible PlayStation 2 projects.

## Nintendo Switch

- Recover more AArch64 call and branch targets, including guarded jump tables, SDK startup callbacks, exception landing pads, and `setjmp` continuations. Improve linking for stripped modules and reviewed link profiles.
- Expand desktop runtime support for SDK startup, offline accounts and networking, audio, input, saves, and applets. Windows exports support a native software-keyboard dialog and an optional settings handoff to the launcher.
- Correct Maxwell and Vulkan texture handling, viewport winding, depth bias, and rendering state. Add VP8 video decoding and optional cubic presentation scaling.
- Reduce overhead in native entry checks, draw submission, and frame presentation. Improve frame pacing and add optional build and presentation tuning.

Switch exports remain experimental. The Windows workflow runs original CPU, module, and desktop fixtures. Retail compatibility varies by title, and physical hardware coverage and adaptive geometry remain limited. [Switch workflow guide](https://github.com/OMGitsMatt45/decomp.wtf/blob/v0.24.0/docs/future/switch.md)

## PlayStation 2

- Stage files from an extracted DVD tree with `tools/extract_assets.py --directory`. The helper verifies each file against the export's SHA-256 inventory and retains the original disc sector addresses. This works for eligible 2048-byte-sector DVD exports with complete file inventories.
- Existing image-backed projects can continue to use their disc images. Existing game builds and saves remain in their own projects.

Download **decompnet-0.24.0-windows.zip**, extract it, and run **windows.cmd**. The wheel, source distribution, installers, and **SHA256SUMS** are also attached.
