# decomp.wtf 0.23.0

This release adds an experimental Nintendo Switch workflow that translates AArch64 code into editable C. It accepts owner-extracted ExeFS modules, standalone NSO files, and homebrew NRO files. The desktop export includes the Kirikae service and Vulkan runtime sources and reports missing native targets.

- `decomp pc switch-inspect` inspects an input and reports its module layout.
- `decomp pc switch-probe` exports a small CPU test project. `decomp pc switch-runtime` exports linked ExeFS modules with a limited set of host services.
- `decomp pc switch-native INPUT OUTPUT --experimental` exports a desktop source project. Rust 1.90 or newer is required for source generation. See the [Switch workflow](https://github.com/OMGitsMatt45/decomp.wtf/blob/v0.23.0/docs/future/switch.md) for build requirements and fixture commands.

Switch desktop execution was qualified on Linux x86-64 with original test programs. Windows desktop execution, adaptive presentation, and retail gameplay remain unqualified. The Windows release checks cover the app and the existing Game Boy Advance, Nintendo DS, Nintendo 3DS, PlayStation, and PlayStation 2 backends. The clean-install smoke test also checks Switch source checksums in the wheel and Windows ZIP.

Download **decompnet-0.23.0-windows.zip**, extract it, and run **windows.cmd**. The wheel, source distribution, installers, and **SHA256SUMS** are also attached. Existing generated projects keep their source snapshots and game data.
